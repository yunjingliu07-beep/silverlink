# Silver Link 银龄连线

连接新加坡社区长者与志愿者的响应式网站。暖白与森林绿界面，支持手机、平板和桌面，大字号模式及键盘操作。

**中英双语：** 点击页面顶部的 `EN`／`中文` 按钮即可切换，语言选择会自动保存。所有界面、任务示例、匹配原因、提示、日期、表单验证与证书均支持双语。切换不会清空现有记录或未提交的表单；老人、志愿者及机构资料按当前语言显示，保留原文和可校对的中英文版本。常用表达用本地词库转换；支持 Translator API 的浏览器可使用本机翻译（可能下载语言模型），未识别内容保留原文，不虚构翻译或姓名。

**当前交付是可完整体验的本机交互演示，不是可供真实服务运营的生产系统。** 所有默认人物、任务、历史时长与奖励均为虚构。数据只保存在当前浏览器的 `localStorage` 中；角色切换不是身份认证。

## 运行

需要 Node.js 20+（检查和单元测试）及 Python 3（本地静态服务），无需安装 npm 依赖。

```bash
npm start
```

访问 http://localhost:5173 。不要直接以 `file://` 打开 HTML，因为浏览器需要通过 HTTP 加载 ES modules。

```bash
npm test          # 19 项业务规则、国际化及角色渲染测试
npm run build    # 校验发布文件及 JS 语法；静态发布目录为 dist/
```

`dist/` 中的源文件就是发布文件，无需打包器或 CDN。可以将整个 `dist/` 上传到任意静态托管服务。所有页面使用 hash 路由，刷新不需要服务器重写规则。

## 如何体验完整流程

1. 志愿者视角打开任务详情，申请任务。
2. 顶部切换为老人视角，在「我的服务」确认预约并查看签到码。
3. 切换志愿者视角，输入签到码开始服务，结束后填写实际时长。
4. 切换老人视角，确认时长并评价志愿者。
5. 志愿者可以提交对老人匿名的服务反馈；演示管理后台可查看。
6. 切换管理员视角，在「管理后台」核实服务。此时才发积分、累计时长。
7. 初始示例为 36 小时；完成并核实两个 2 小时任务，即可在「积分与荣誉」下载带明显演示标记的 40 小时证书。

有未关闭反馈的任务无法核实。拒绝、取消或未经核实的任务不增加服务时长及积分。任务申请检测时间重叠，签到码只能用于当前预约，积分不会重复发放。

## 已实现

- 新加坡中部社区 SVG 示意地图、标记选择、放大缩小、地图／列表视图及任务分类。
- 按语言、技能、开始时段和示例距离排序，展示匹配原因；必备条件不符时禁止申请。
- 志愿者及老人资料编辑，空闲时段和语言技能偏好保存。
- 文字发布需求，本地关键词规则生成可编辑草稿，确认后加入地图。
- 浏览器支持时可选语音输入，明确请求同意后调用浏览器识别功能；不保存录音。
- 申请、预约、签到、签退、双方时长确认、管理员核实的完整状态流转。
- 双向独立评分、服务历史、已核实时长、平均分与好评统计。
- 核实后每小时 10 个演示积分；模拟兑换与积分流水。
- 40 小时社区服务证书及 100 次好评／4.5 分荣誉门槛。
- 演示证书 HTML 下载及本机验证页面，清楚注明不具正式效力。
- 紧急联系人保存、用户主动点击电话链接、任务问题反馈与管理员处理。
- 本机数据导出、清空重置及同浏览器其他标签页状态更新。

## 明确未接入的能力

| 能力 | 当前实现 | 生产接入要求 |
| --- | --- | --- |
| 真实账户、权限与身份 | 四种本机演示角色 | 后端认证、服务端角色授权及账户恢复 |
| 跨用户实时任务及预约 | localStorage；仅同浏览器标签同步 | 数据库、事务、实时订阅／通知、防重复接单 |
| 精确地图及导航 | 原创 SVG 社区示意图、固定示例距离 | 地图服务、授权定位及服务端地址访问控制 |
| AI 需求解析 | 明示的本地关键词分类 | 后端模型调用、结构化输出、用户确认及敏感数据最小化 |
| Singpass | 仅展示待接入状态 | 官方接入资格、正式认证流程和身份资料管理 |
| 服务录音与风险识别 | 未录音、未监测 | 双方明确同意、撤回与替代流程、加密存储及保留政策 |
| 自动呼叫与紧急通知 | 用户点击 `tel:` 链接 | 电话／消息服务、联系人授权、值班响应机制与可靠告警 |
| 伙伴奖励及 CDC Vouchers | 模拟积分及奖励；CDC 兑换禁用 | 正式合作、授权、兑换账本及兑付机制 |
| 正式证书与独立核验 | 本机演示下载及本机核验 | 可信后台签发、独立公开验证链接、防篡改与撤销记录 |

不应把 localStorage 演示部署当作真实服务平台，也不应在其中输入真实个人敏感资料。客户端角色与匿名展示不能构成生产环境的数据访问隔离。

## 项目结构

```text
dist/
  index.html       页面入口及可访问性基础
  app.js           页面、表单、路由与交互
  domain.js        匹配、服务状态、积分及证书规则
  i18n.js          语言偏好、翻译函数及地区格式
  i18n-en.js       英文界面翻译词库
  i18n-data.js     示例数据及系统记录的语言显示
  style.css        响应式视觉及大字号样式
  favicon.svg      原创品牌图标
scripts/check.mjs  零依赖静态检查
tests/
  domain.test.js   业务规则测试
  i18n.test.js     翻译覆盖及用户数据保留测试
  browser.py       可选 Playwright 端到端检查
  bilingual-browser.py  双语、表单保留与响应式回归检查
.openai/hosting.json  Sites 私人预览托管配置
```

浏览器集成检查需要另行安装 Python Playwright 和 Chromium。在另一个终端运行网站后：

```bash
CHROMIUM_PATH=/usr/bin/chromium python tests/browser.py
CHROMIUM_PATH=/usr/bin/chromium SILVERLINK_TEST_LANGUAGE=en python tests/browser.py
CHROMIUM_PATH=/usr/bin/chromium python tests/bilingual-browser.py
```

测试覆盖中英两种语言下的完整服务、双方评价、证书下载、积分兑换、任务发布与持久化、紧急联系人、用户输入转义，以及四种宽度下的六个页面。双语专项检查还覆盖语言记忆、日期、未提交表单和错误提示保留、跨标签页语言同步、大字号布局与匹配字段稳定性。

## 后续生产化建议

建议保留当前界面，将业务状态迁移到有事务支持的后端数据库；先完成账户与权限、任务与预约、核实与评价，再接入地图、通知和官方身份能力。生产中所有积分与证书条件必须由服务端判断，评价匿名性和地址可见性必须在 API 层执行。


## 更新记录：七项社区服务体验改进（2026-10-19）

以下记录对应功能提交 `c6d165ef1109ce36336d75bf353b83e493f728d5`（原提交标题为 `Update Site source`）。持续同步 GitHub 的项目规则另见提交 `22482d2fca8be42bc66d770ac4a43f2a0e438a7d`。本次文档提交补充需求与实现说明，不重复修改功能、不重写已有历史。

### 1. 老人与志愿者填写的资料随中英文切换

- 资料按当前界面语言显示，保留原文以及可编辑、可校对的中英文版本；机构资料也采用同样机制。
- 常见兴趣、生活习惯和服务需求用本地词库转换；支持浏览器 Translator API 时可翻译可见资料字段，可能需要下载本机语言模型。
- 编辑原文后清除过期译文。无法识别或无法翻译的内容保留原文；不自动编造姓名翻译，也不承诺所有浏览器都能翻译任意自由文本。

### 2. 老人视角独立于志愿者工作界面

- 老人视角隐藏累计服务时长等四项志愿统计，以及奖励、志愿匹配偏好和匿名志愿反馈。
- 仅展示申请帮助、自己的申请、老人资料和安全内容；直接访问不适用的页面 hash 时返回角色首页。
- 这些是本机 Demo 的界面隔离；真实账户权限和跨用户数据隔离仍需服务端实现。

### 3. 四项志愿统计可查看明细并申诉

- 点击服务时长、完成次数、服务评分、爱心积分卡片，打开对应历史记录标签页。
- 每条明细展示记录编号、服务类别、日期、服务对象、时长、获得积分和评分；积分页另列余额与兑换支出。
- 初始 18 条示例记录合计 36 小时、360 积分、17 次好评、评分合计 86；新核实的服务自动加入记录。
- 支持缺失记录、时长、积分和评分申诉，填写依据后进入演示管理后台；管理员回复后，志愿者可查看处理状态和答复。
- 申诉仅保存于本机，不通知真实工作人员；结案不会自动改写积分或服务时长。

### 4. 老人首页改为服务介绍和申请引导

- 展示陪诊、手机教学、日常采购和陪伴四类服务，并提供三步申请引导及申请入口。
- 增加志愿者帮助老人使用平板进行视频通话的 AI 生成图片，页面明确标注虚构人物及场景。
- 本次未使用真实用户照片。未来如使用真实照片，应先取得相关老人和志愿者对平台公开展示的授权；Demo 不声称已取得不存在的真实人物授权。

### 5. 老人地图展示附近已完成的服务故事

- 地图展示社区服务成果故事，可选择标记查看相应内容，并支持中英双语。
- 包含 9 月 1 日李大爷找到志愿者陪诊、9 月 3 日王奶奶学会视频通话，以及购物和公园陪伴示例。
- 地图为社区示意图，故事明确标注为虚构 Demo，不代表真实服务记录或实时地理数据。

### 6. 地图上方增加附近志愿者人数提示

- 显示“附近有 100+ 位志愿者，放心寻求帮助吧”及对应英文，并提供申请帮助按钮。
- 人数明确标注为演示数目，未接入实时人数统计。

### 7. 新增机构视角与老人批量录入

- 面向养老院等机构，沿用老人首页、服务介绍、成果地图和申请体验，增加批量老人资料与需求录入。
- 支持一次录入 1–30 位老人，包含称呼、年龄、语言、服务类别、需求内容、提醒，以及服务区域、日期和时长。
- 提供代理授权勾选与发布预览；发布后为每位老人生成独立需求，进入志愿者能力匹配列表，并检测预约时间重叠。
- 老人与机构的申请列表按角色区分，避免混合展示；仍属于本机演示数据。
